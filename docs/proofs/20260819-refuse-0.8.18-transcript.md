# TWZRD Internal Mechanism Proof — refuse before sign, 0.8.18

**Date:** 2026-08-19 UTC · **Package:** `twzrd-x402-gate@0.8.18` (published, npm)
**Classification:** internal mechanism proof on a TWZRD-owned fixture.

> This is **not** external adoption evidence. The seller is a TWZRD-owned synthetic
> fixture, and the run is self-operated. The transcript itself records
> `"closes_external_adoption_metric": false`. Milestone 3 adoption requires an
> independently operated refusal or seller integration; this artifact cannot satisfy it.

## Reproduction

Clean checkout, no TWZRD credentials, no wallet, no keys:

```bash
npm install twzrd-x402-gate@0.8.18 x402-solana@2.1.0 \
            @x402/core @x402/fetch @x402/svm @solana/kit @scure/base js-sha3
node node_modules/twzrd-x402-gate/bin/twzrd-gate-eval-refuse.js
```

The harness registers a signer spy that counts invocations and raises
`TWZRD_SIGNER_SPY_STOP_BEFORE_SIGNATURE`. No transaction is ever signed or broadcast.

## Known gap — transcript schema vs. proposal acceptance fields

The grant proposal names five acceptance fields. `twzrd.gate_eval_refuse.v1` emits two
of them under those exact names:

| proposal field | emitted? | current form |
|---|---|---|
| `signer_invocation_count=0` | yes | — |
| `usdc_spent=0` | yes | — |
| `decision=block` | no | `twzrd_decision` |
| `approved=false` | no | `preflight_immediately_before_run.can_spend=false`, `verified` |
| `transaction_broadcast_count=0` | no | absent; `payment_retry_count` is a different measure |

Reconciling the emitted schema with the published acceptance criteria — so a reviewer can
assert the named fields directly — is Milestone 1 work.
